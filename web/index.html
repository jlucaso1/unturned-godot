Point a browser at your Unturned install

This page reads a real Unturned folder straight off your disk using the browser's directory picker. Nothing is uploaded, zipped or copied: the browser hands the page a capability scoped to the one folder you choose, and the game's files stay exactly where Steam put them — the same rule the desktop build follows.

Pick the steamapps/common/Unturned folder, or the Steam library above it to include Workshop maps.

Selecting the folder is the part that works today. Actually running the game here does not: Godot 4 refuses to export a C#/.NET project to the web at all, which this repo verifies rather than assumes. See docs/WEB-EXPORT.md for the exact error, what would have to change, and how this file layer plugs into the engine when it does.
